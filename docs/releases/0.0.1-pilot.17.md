# kidOS 0.0.1-pilot.17 — Developer Preview

The first public-source preview of kidOS: a local-first, Windows 95-inspired desktop for children, built on Linux. It includes browser tools for projects, games, reading, local educational sites and on-device letters, with a separately provisioned native launcher for creative tools and games.

This release adds contribution and security guidance, reviewed public-source packaging checks, automated CI, repeatable release verification and a draft-prerelease workflow. It includes the pilot.16 desktop fixes for multiple windows, stable shortcuts and temporary launch notices.

## Download and try

For local development, use the full source at this tag, Node.js 22 or 24, `npm test`, then `npm start`. Open http://127.0.0.1:8787. No npm dependency installation or cloud account is required.

The attached `kidos-0.0.1-pilot.17.tar` is an allowlisted portable source bundle with `RELEASE.json`; its `.sha256` file checks download integrity. Extract into an empty directory and read `os/raspberry-pi/README.md` before installation. GitHub's automatically generated source archives contain the full checkout and are not interchangeable with the portable installer bundle. No bootable image, Node runtime, native application binaries, VM data or proprietary games are included.

## Verification and limits

Release preparation runs the complete automated test suite, verifies archive reproducibility and rehearses installation in temporary staging directories. CI results on the matching commit provide the recorded host/Node matrix. Earlier pilot.16 acceptance in Debian ARM64 verified Paint, Files and Solitaire together, stable desktop shortcuts and dismissing launch notices; that is bounded prior-runtime evidence, not a fresh graphical acceptance of this package.

Physical Raspberry Pi operation, touch/controller support and complete audio/USB acceptance remain unverified. Parent authentication, OS-level child-code containment, onboarding, signed device updates and recovery media are unfinished. This is for supervised developer experimentation, not independent child use or a giftable appliance. Native windows are not yet fully integrated into the browser taskbar. Mailbox is local to one computer. Offline Wikipedia is not included.

Updates are manual and optional. Follow future releases through GitHub notifications; an in-device updater is planned separately. Preserve household data and native files, and read migration/backup guidance before changing installations. SHA-256 checksums alone do not authenticate a release publisher.
